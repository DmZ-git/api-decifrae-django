## 📞 Se der erro:

**"password authentication failed"**
→ Senha em DATABASE_URL está errada

**"FATAL: database does not exist"**
→ Deve ser "postgres", não outro banco

**"ImproperlyConfigured: DATABASE_URL"**
→ Falta copiar DATABASE_URL no Render

**"CORS policy blocked"**
→ Frontend não consegue acessar API  
→ Verifique CORS_ALLOWED_ORIGINS = https://front-decifrae.vercel.app (sem /api no final)
